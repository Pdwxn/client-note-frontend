# Client Notes

Client Notes es un gestor de clientes y notas pensado para profesionales independientes que necesitan organizar su información de clientes y las interacciones con cada uno de ellos.

## Qué permite hacer la app

### Gestión de clientes
Cada cliente tiene un perfil donde puedes guardar su nombre, correo electrónico, teléfono y empresa para la que trabaja. Puedes crear nuevos clientes, editar sus datos cuando cambian y eliminarlos cuando ya no los necesitas. Todos tus clientes se mostram en una lista ordenada en la barra lateral izquierda.

### Notas por cliente
Para cada cliente puedes crear tantas notas como quieras. Las notas pueden ser de diferente tipo: ideas (para guardar inspiración), reuniones (para resumir lo que hablaste), llamadas (para registrar una conversación) o contratos (para seguir el estado de un proyecto). Así tienes todo ordenado y separado por cliente.

## Cómo funciona

La app está dividida en dos partes que funcionan juntas: el frontend (lo que ves en el navegador) y el backend (la API que guarda y procesa los datos). Cada usuario tiene sus propios clientes y notas, nadie puede ver la información de otros usuarios.
